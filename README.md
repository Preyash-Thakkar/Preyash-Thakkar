# Hi, I'm Preyash. 👋

I am a Backend Developer focused on building scalable systems, real-time communication pipelines, and seamless hardware-to-software integrations. I enjoy collaborating with engineering teams to solve complex challenges, from migrating cloud infrastructures to orchestrating low-level DSP pipelines.

### ⚡ What I do
- **Backend Architecture:** Designing resilient APIs and microservices using **Node.js**, **Express**, and **MongoDB**.
- **Real-Time Systems:** Building highly concurrent multiplexing engines and offline-first edge syncs using **WebSockets**, **RabbitMQ**, and **Redis**.
- **Hardware Integration:** Bridging web platforms with medical-grade hardware via **Web BLE** and custom DSP routing.
- **Cloud & DevOps:** Containerizing applications with **Docker** and establishing automated CI/CD pipelines on **Microsoft Azure**.
